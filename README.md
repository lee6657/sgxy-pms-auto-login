# 基建系统自动登录

适用于以下登录页的 ScriptCat 用户脚本：

`https://www.sgxy-pms.sgcc.com.cn:20443/webauth/login.html`

## 安装

在浏览器中打开下面的地址，由 ScriptCat 接管安装：

https://raw.githubusercontent.com/lee6657/sgxy-pms-auto-login/main/sgxy-pms-auto-login.user.js

## 使用

1. 首次打开目标登录页时，点击右上角“自动登录”悬浮按钮。
2. 填写账号、密码和 OCR 模型。
3. 模型既可以从常用名称中选择，也可以直接输入中转站支持的自定义模型名。
4. OCR 请求固定发送到 `https://api.playmachine.cn/v1/chat/completions`，设置窗口不再显示密钥和中转站地址。
5. API Key 只保存在本机 ScriptCat 存储中，不会上传到 GitHub；后续自动更新会继续沿用已保存的密钥。
6. 后续也可从 ScriptCat 的脚本菜单中选择“打开自动登录设置”修改账号、密码和模型。
7. 脚本会根据 `@updateURL` 自动检查新版本。

OCR 返回空结果或格式异常时，脚本会等待 10 秒后重试，不会主动连续刷新验证码。只有网站明确提示验证码错误时才会刷新验证码图片。

脚本会在页面和验证码图片就绪后立即开始识别，并以较短间隔检测登录表单。成功填入验证码后仅短暂等待，并按照真实鼠标点击的顺序先让验证码输入框失焦、再聚焦登录按钮并点击，确保网站内部表单值已经同步，同时避免固定等待 2 秒导致验证码在提交前失效。

脚本还会锁定本次 OCR 对应的验证码图片版本。如果图片在识别期间或登录前的短暂等待期间被网页刷新，会立即丢弃旧结果并取消本次登录，避免把上一张图片的正确答案提交给新验证码。

点击登录后会等待至少 3 秒再确认验证码错误，并忽略提交前已经存在的旧错误提示，避免登录过程中误刷新正确的验证码。

## 安全说明

仓库中不包含账号、密码或 API Key。个人安装文件可一次性内嵌 API Key，将其写入 ScriptCat 本地存储；公开更新文件始终保留占位符。不要把包含个人配置的脚本或备份上传到公开仓库。
